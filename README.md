# Учёт личных расходов

Учебный веб-проект по дисциплине «Введение в интернет-технологии».

Вариант задания: №23 — Учёт личных расходов.

## Назначение проекта

Проект предназначен для учёта личных расходов. Пользователь может добавлять траты, относить их к категориям, просматривать историю расходов и получать сводку за период.

## Текущее состояние

Выполнена Практическая работа №1:

- разработаны 5 связанных страниц сайта;
- использована семантическая HTML-разметка;
- стили вынесены в отдельный файл `css/style.css`;
- макет построен с помощью Flexbox и CSS Grid;
- реализована адаптивность для экранов шириной от 360 px;
- добавлен собственный логотип;
- все изображения имеют осмысленный атрибут `alt`;
- в каталоге размечено 12 категорий расходов;
- элементы фильтрации и сортировки пока только размечены;
- подготовлена страница добавления расхода и сводки;
- подготовлена страница контактов с формой обратной связи.

## Структура страниц

1. `index.html` — главная страница.
2. `catalog.html` — каталог категорий расходов.
3. `category.html` — страница одной категории.
4. `add.html` — добавление расхода и сводка.
5. `contacts.html` — контакты и форма обратной связи.
